# The Old Ladies Game Club

A web app for an indie game review club — like a book club, but for games.

**Pick a game. Play it. Come back. Talk about it.**

Each month the community picks a Game of the Month, members play it, then return to leave reviews and discuss it together.

## Tech stack

- [Next.js](https://nextjs.org/) (App Router)
- JavaScript
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)

**In use:** Steam Store API (game metadata)  
**Planned:** Firebase (auth + database)
